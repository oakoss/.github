# Contributing to Oak OSS

Thanks for your interest in contributing to Oak OSS projects!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a branch for your changes
4. Make your changes
5. Submit a pull request

## Development

Each repository has its own setup instructions in its README. Check the project's README for:

- Package manager (pnpm, bun, etc.)
- Installation steps
- Development commands
- Test instructions

## Pull Requests

- Keep PRs focused on a single change
- Write clear commit messages using [conventional commits](https://www.conventionalcommits.org/)
- Update documentation if needed
- Add tests for new features
- Ensure all tests pass

## Code Style

We use automated formatting and linting via pre-commit hooks. These run automatically when you commit.

## Questions?

- Open a [discussion](https://github.com/orgs/oakoss/discussions)
